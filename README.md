# Neon Sokak — prototype build

A third-person walk through a rain-wet neon back alley at night. Step into the shops: a ramen bar, a TV repair shop, a neon bar and an arcade.

**Download (Windows):** see [Releases](../../releases/latest) → `NeonSokak-Windows.zip`

1. Unzip, then double-click `NeonSokak.exe` (keep `NeonSokak.pck` next to it).
2. If Windows SmartScreen appears: "More info" → "Run anyway".

Controls: WASD move · Shift run · mouse look · Esc release mouse · F11 fullscreen · gamepad supported.

Credits for third-party assets are in `CREDITS.txt` inside the zip.
